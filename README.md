# One Day Keizai - プラグイン説明書

PvPサバイバル経済プラグイン for Paper 1.20.1

---

## 概要

One Day Keizai は、戦闘・借金・犯罪者システムを組み合わせたハードコアサバイバルプラグインです。プレイヤーの行動には常にリスクが伴い、ログアウトの仕方にまで注意が必要です。

**前提プラグイン**: Vault

---

## コマンド一覧

| コマンド | 説明 |
|---|---|
| `/bal` | 自分の所持金を確認する |
| `/debt lend <プレイヤー> <金額> <分> [利率%]` | 指定プレイヤーにお金を貸す（期限・利子付き） |
| `/debt repay <債権者> <金額>` | 借金を返済する |
| `/debt forgive <債務者>` | 貸したお金を帳消しにする |
| `/debt list` | 自分に関連する借金の一覧を表示する |


---

## ゲームシステム

### 犯罪者システム

プレイヤーは以下の条件で **犯罪者** になります。

- **無実のプレイヤーを3人殺害した場合**（自分から先に攻撃して倒した場合のみカウント）
- **借金の返済期限を過ぎた場合**

犯罪者になると：

- 名前タグが **赤色** になる
- 死亡時に **全アイテム・経験値をドロップ** する

### 正当防衛の判定

相手が先に攻撃してきた場合、その相手を倒しても「無実キル」にはカウントされません。最初に攻撃を仕掛けた側が加害者として記録されます。

### 戦闘と死亡

**一般プレイヤー（非犯罪者）が死亡した場合：**
- アイテム・経験値は保持される
- 所持金の **33%** がキラーに奪われる

**犯罪者が死亡した場合：**
- 全アイテム・経験値をドロップ
- 所持金の **33%** がキラーに奪われる

### リスポーン保護

死亡してリスポーンすると、**10分間の保護状態** になります。

- 名前タグが **緑色** になる
- 攻撃できず、攻撃されない
- 初期装備として **石のツルハシ** と **石の斧** が配布される

## 借金システム

### 貸付の流れ

1. `/debt lend <相手> <金額> <期限(分)> [利率%]` で相手にお金を貸す
2. 指定した金額（元金）が即座に相手に送金される
3. 利率を指定した場合、返済額は **元金 + 利子** になる（例: 1000を利率10%で貸すと返済額は1100）
4. 利率は省略可能（省略時は0%）
5. 期限内に返済されなかった場合、借り手は **犯罪者** になる

### 返済

- `/debt repay <貸主> <金額>` で一部または全額を返済可能

### 帳消し

- `/debt forgive <借主>` で貸主が借金を免除できる

### 借金を抱えたプレイヤーが死亡した場合

- キラーと債権者が **別人** の場合：被害者の所持金の50%がキラーへ、50%が債権者へ
- キラーと債権者が **同一人物** の場合：全額が債権者（キラー）へ
- 死亡により借金は **帳消し** になる

## ログアウトルール

### 安全なログアウト

以下の条件を **両方** 満たすと安全にログアウトできます。

1. **ベッドの近く**（半径5ブロック以内）にいること
2. ベッド付近に **15秒間** 滞在すること

条件を満たすまでのカウントダウンがアクションバーに表示されます。

### 危険なログアウト

ベッドから離れた場所でログアウトした場合：

- **15分間の猶予** が与えられる
- 15分以内に再ログインすれば **ペナルティなし**
- 15分を超えると **インベントリの全アイテムが削除** される

### 戦闘中のログアウト

最後にダメージを受けてから **30秒以内** にログアウトすると、戦闘中ログアウトと判定されます。

- 最後の攻撃者に所持金の **33%** が渡る
- 犯罪者の場合はアイテムもドロップする
- サーバー全体にメッセージが通知される

## ワールド制限

- **ネザー** および **エンド** へのポータル移動は禁止されています

---

## 設定項目（config.yml）

| 項目 | デフォルト値 | 説明 |
|---|---|---|
| `money-steal-ratio` | 0.33 | 死亡時に奪われる所持金の割合 |
| `innocent-kill-limit` | 3 | 犯罪者になるまでの無実キル数 |
| `respawn-protection-seconds` | 600 | リスポーン保護の秒数 |
| `combat-logout-seconds` | 30 | 戦闘中と判定される秒数 |
| `logout-grace-minutes` | 15 | ログアウト猶予時間（分） |
| `bed-logout-radius` | 5 | 安全ログアウトのベッド距離（ブロック） |
| `bed-stay-seconds` | 15 | 安全ログアウトに必要なベッド滞在秒数 |
